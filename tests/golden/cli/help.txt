bowline command shell

Discovery:
  help                 Show human or JSON help for every CLI command.
  version              Print CLI version and protocol compatibility.
  contract             Print the machine-readable CLI command and output contract.

Workspace:
  update               Check for or install the latest Bowline release.
  login                Sign in and onboard this machine with the default ~/Code workspace.
  logout               Clear the saved local account session without removing device trust.
  status               Inspect workspace, sync, and safe next actions.
  setup                Set up this machine or prepare one project for Bowline.
  conflicts            List files whose incoming version is waiting beside them.
  resolve              Reconcile one conflict: keep your file, take the incoming one, or diff them.
  deletions            Show the deletion sync refuses to publish, and confirm it.
  events               List recent workspace events.
  tui                  Open the terminal workspace UI.
  forget-local         Remove one materialized project from this device after preview.
  archive              Hide one project from default namespace views without deleting local bytes.
  purge                Schedule remote destruction for an archived project after a grace window.

Trust:
  device approve       Approve a pending device trust request.
  device deny          Deny a pending device trust request.
  device revoke        Revoke a trusted device.
  device list          List local device records.
  device request       Raise a device approval request for this machine.
  device accept        Accept an encrypted device grant for this machine.
  device key-status    Report whether this device holds workspace key material.
  recover status       Report Recovery Key state for this workspace.
  recover create       Create a Recovery Key and print its words once.
  recover verify       Check Recovery Key words from stdin without granting access.
  recover rotate       Mint a fresh Recovery Key and invalidate the previous one.
  recover revoke       Permanently revoke a Recovery Key.
  recover use          Grant this device workspace access with Recovery Key words from stdin.

Remote:
  connect              Inbound SSH: install and trust a machine you own.

Work:
  work create          Create or reuse a named work view for a project.
  work list            List work views.
  work diff            Show the diff for a work view.
  work review          Preview whether a work view is ready to accept.
  work accept          Apply a review-ready work view.
  work discard         Discard a work view.
  work restore         Restore a discarded work view.
  work cleanup         Preview or apply cleanup for retained work views.

Daemon:
  daemon start         Start the local daemon process.
  daemon stop          Stop the local daemon process.
  daemon status        Inspect daemon process and service state.
  daemon install       Install or update the OS service for the daemon.
  daemon restart       Restart the installed daemon service.
  daemon uninstall     Uninstall the daemon OS service.

Support:
  diagnostics collect  Print a redacted diagnostics bundle.
  doctor               Run read-only engine diagnostics with redacted, fixed reason codes.

Run `bowline help <command>` for options and examples, or `bowline contract --json` for the machine contract.
